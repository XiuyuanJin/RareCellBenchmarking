# RareCellBenchmarking

Code for **“A systematic benchmark and practical guide for rare-cell detection in single-cell RNA-seq data.”**

This repository contains analysis scripts for benchmarking existing rare cell detection methods.

## Software requirements

- R version 4.2.3
- Python version 3.9


## Installation

For detailed installation instructions for each rare cell detection method, please refer to its original publication and accompanying software documentation.

## Demo

To use your own data, adapt the example code and update the input and output paths accordingly.
